UD2 Programación en C · Tema 5

Estructuras de control: selección y repetición

UD2 Programación en CProblemas en C

Desde cero

Objetivo: Resolver problemas con if, if-else, switch, while, do-while y for, anidar y apilar estructuras, validar entradas con bucles y evitar break/continue.

Selección: única (if), con alternativa (if-else, cadenas else if) y múltiple (switch(expr){case k: … break; default: …}, solo con enteros/char; sin break cae al siguiente case). Repetición: while (evalúa antes, 0 o más veces), do-while (evalúa después, al menos una vez: ideal para menús y para validar entradas), for(ini; cond; inc) (contadores conocidos). break sale del bucle y continue salta a la siguiente iteración: evitarlos con banderas.

Patrones que caen en todos los exámenes: menú repetido con do-while + switch hasta la opción de salir (círculos, cuadrado mágico); validación: do{ printf; scanf; } while(valor fuera de rango); (edad, pulso, porcentaje); acumuladores y contadores (suma += x; cont++); bucles anidados para recorrer matrices o pintar patrones; búsqueda con bandera for(i=0; i<n && !encontrado; i++); centinela (leer hasta que se teclee 0); simulación de moneda al aire con rand.

Lo que tienes que saber

  • do { printf("Edad: "); scanf(" %d", &edad); } while (edad <= 0 || edad > 110);
  • for (i = 0; i < n; i++) for (j = 0; j < n; j++) … recorre n² celdas; for (j = 0; j <= i; j++) pinta un triángulo.
  • switch(op){ case 1: …; break; case 2: …; break; default: printf("No válida"); }
  • Bucle con bandera en vez de break: encontrado = 0; i = 0; while (i < n && !encontrado) { if (v[i]==x) encontrado = 1; else i++; }
  • Paridad n % 2 == 0; último dígito n % 10; quitar dígito n /= 10; dígitos de un número: do-while hasta que n sea 0.

Cómo se resuelve

  1. Decide la estructura por la pregunta: ¿se sabe cuántas veces? for; ¿al menos una vez? do-while; ¿quizá ninguna? while.
  2. Escribe la condición de continuar, no la de parar (while(x<0 || x>10) repite mientras sea inválido).
  3. Traza a mano dos o tres iteraciones con una tabla de variables antes de dar por bueno el bucle.

Trampas típicas

  • Punto y coma tras el for o el while (while(c); bucle vacío).
  • Olvidar break en el switch.
  • Condición con = en vez de ==; comparar cadenas con == (usa strcmp).
  • Bucle que nunca modifica su variable de control.

Problema tipo

Enunciado

(Problema de examen: control cardíaco, Karvonen) Implementa pide_datos_fisicos(int *edad, int *reposo) (edad 1-110, reposo 30-120, se vuelve a pedir hasta que sea válido), pulsaciones_por_minuto(edad, reposo, intensidad) con la fórmula \(((220-edad)-reposo)\cdot intensidad/100+reposo\) y el main que pide intervalos e incremento y muestra la tabla.

✓Ver solución paso a paso
#include <stdio.h>
void pide_datos_fisicos(int *edad, int *pulsoreposo);
void pide_intervalos(int *m, int *l);
int pulsaciones_por_minuto(int edad, int pulsoreposo, int intensidad);
int calcula_posiciones_rango(int min, int max, int inc, int edad, int pulsoreposo, int v[]);

int main(void) {
    int edad, reposo, min, max, inc, n, i, valores[101];
    char resp;
    do {
        pide_datos_fisicos(&edad, &reposo);
        if (reposo > 90) printf("Aviso: pulso en reposo alto, consulte a su medico\n");
        pide_intervalos(&min, &max);
        do { printf("Incremento (1-10): "); scanf(" %d", &inc); } while (inc <= 0 || inc > 10);
        n = calcula_posiciones_rango(min, max, inc, edad, reposo, valores);
        for (i = 0; i < n; i++)
            printf("Intensidad %3d %%: maximo %d ppm\n", min + i*inc, valores[i]);
        printf("Repetir? (s/n): "); scanf(" %c", &resp);
    } while (resp == 's' || resp == 'S');
    return 0;
}
void pide_datos_fisicos(int *edad, int *pulsoreposo) {
    do { printf("Edad (1-110): "); scanf(" %d", edad); } while (*edad <= 0 || *edad > 110);
    do { printf("Pulso en reposo (30-120): "); scanf(" %d", pulsoreposo); } while (*pulsoreposo < 30 || *pulsoreposo > 120);
}
void pide_intervalos(int *m, int *l) {
    do {
        printf("Intensidad minima (%%): "); scanf(" %d", m);
        printf("Intensidad maxima (%%): "); scanf(" %d", l);
    } while (*m >= *l || *m <= 0 || *l > 100);
}
int pulsaciones_por_minuto(int edad, int pulsoreposo, int intensidad) {
    return ((220 - edad) - pulsoreposo) * intensidad / 100 + pulsoreposo;   /* Karvonen */
}
int calcula_posiciones_rango(int min, int max, int inc, int edad, int pulsoreposo, int v[]) {
    int n = 0, p;
    for (p = min; p <= max; p += inc) v[n++] = pulsaciones_por_minuto(edad, pulsoreposo, p);
    return n;
}

Fíjate: la validación va en do-while dentro de la función que lee (devuelve por referencia con punteros), el cálculo en una función aparte que solo hace el cálculo, y main solo coordina. El apartado e) pide los cuatro valores en un vector: void pide_datos(int v[4]) con scanf(" %d", &v[0]).

Responde antes de desplegar.

1¿Cuántas veces se ejecuta el cuerpo de for(i=10;i>0;i-=3)?

i = 10, 7, 4, 1: cuatro veces.

2Diferencia entre while y do-while.

while evalúa la condición antes (puede no ejecutarse); do-while después (se ejecuta al menos una vez), por eso sirve para menús y validaciones.

3Escribe un bucle que sume los números tecleados hasta que se introduzca un 0.

suma=0; do { scanf(\" %d\",&x); suma+=x; } while (x!=0);

srand(time(NULL)); caras=0; for(i=0;i<1000;i++) if(rand()%2==0) caras++;
