UD2 Programación en C · Tema 4

Tipos de datos primitivos y entrada/salida

UD2 Programación en CProblemas en C

Desde cero

Objetivo: Declarar variables y constantes, usar los tipos primitivos de C, los operadores y su precedencia, las conversiones implícitas y explícitas, y las funciones printf/scanf con sus formatos.

Un tipo de dato define el conjunto de valores y las operaciones. Primitivos de C: char (1 byte), short, int, long, float, double, void; compuestos: vectores, estructuras, uniones, punteros, enumerados. C es débilmente tipado y no permite definir tipos nuevos (sí alias con typedef). Terna de una variable ⟨R, K, T, N⟩: espacio de memoria R (lo asigna el compilador), valor K, tipo T y nombre N (los da el programador); una variable existe desde que se declara.

Conversión de tipos: implícita (promoción) al asignar un tipo menor a uno mayor en el orden char, short, int, long, float, double; explícita con cast (tipo)expr. Trampa clásica: (double)(1/2) vale 0.0 porque la división entera se hace antes; (double)1/2 vale 0.5. No se puede castear el lado izquierdo de una asignación.

Operadores: aritméticos (+ − * / % con / entera entre enteros), relacionales (== != < > <= >=), lógicos (&& || !), asignación compuesta (+= −= *=), incremento (++i antes, i++ después), condicional (?:), sizeof. Precedencia: () → ++ −− ! (cast) → * / % → + − → relacionales → == != → && → || → asignación. Las expresiones lógicas valen 0 (falso) o distinto de 0 (verdadero).

E/S con <stdio.h>: printf("formato", args) con %d (int), %hd (short), %ld (long), %f (float/double), %lf (double; en printf %f vale), %.2lf (dos decimales), %c, %s, %x, %%, \n, \t. scanf(" %d", &x) necesita la dirección (&) salvo para cadenas (ya son punteros) y %lf para double; el espacio antes de %c o %d descarta blancos y saltos pendientes. Constantes con #define PI 3.14159 o const. Bibliotecas: <math.h> (sqrt, pow, fabs; compilar con -lm), <stdlib.h> (rand, srand, malloc), <string.h> (strlen, strcpy, strcmp), <ctype.h> (isalpha, isdigit, isprint), <time.h> (time).

Lo que tienes que saber

  • División: 7/2 = 3, 7%2 = 1, 7/2.0 = 3.5, (double)7/2 = 3.5, (double)(7/2) = 3.0.
  • int a=5; b=a++ + ++a; es indefinido: no lo escribas; x=*++p+i con p→a[0]: avanza p a a[1] y suma i.
  • Formatos: %d int, %ld long, %hd short, %f/%lf double, %c char, %s cadena, %5.2f ancho 5 con 2 decimales.
  • scanf(" %c",&ch) — el espacio evita leer el Enter anterior. scanf("%s",cad) sin &.
  • Números aleatorios: srand(time(NULL)); r = rand()%N; (0…N−1).

Cómo se resuelve

  1. Para «¿qué imprime?»: anota el tipo de cada subexpresión; si los dos operandos son enteros la división es entera.
  2. Resuelve de dentro a fuera respetando precedencia y asociatividad (asignación de derecha a izquierda).
  3. Comprueba los formatos de printf frente a los tipos: un %d con un double imprime basura.

Trampas típicas

  • Olvidar & en scanf (o ponerlo en una cadena).
  • Comparar con = en vez de ==.
  • Creer que (double)(1/2) es 0.5.
  • %lf con float en scanf (float usa %f).

Problema tipo

Enunciado

(Test febrero 2019) ¿Qué imprime?

#include <stdio.h>
int main(void) {
    int a[5] = {10,20,30,40,50};
    int *p = a, i = 2;
    printf("%d", *++p + i);
    return 0;
}

Y: double x = (double)(1/2); printf("%.1lf", x);

✓Ver solución paso a paso

++p hace que p apunte a a[1] (20); *++p + i = 20 + 2 = 22 (opción d). La segunda imprime 0.0: 1/2 es división entera.
