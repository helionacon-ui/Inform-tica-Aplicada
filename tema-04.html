UD2 Programación en C · Tema 4

Tipos de datos primitivos y entrada/salida

UD2 Programación en CProblemas en C

Desde cero

Objetivo: Declarar variables y constantes, usar los tipos primitivos de C, los operadores y su precedencia, las conversiones implícitas y explícitas, y las funciones printf/scanf con sus formatos.

Un tipo de dato define el conjunto de valores y las operaciones. Primitivos de C: char (1 byte), short, int, long, float, double, void; compuestos: vectores, estructuras, uniones, punteros, enumerados. C es débilmente tipado y no permite definir tipos nuevos (sí alias con typedef). Terna de una variable ⟨R, K, T, N⟩: espacio de memoria R (lo asigna el compilador), valor K, tipo T y nombre N (los da el programador); una variable existe desde que se declara.

Conversión de tipos: implícita (promoción) al asignar un tipo menor a uno mayor en el orden char, short, int, long, float, double; explícita con cast (tipo)expr. Trampa clásica: (double)(1/2) vale 0.0 porque la división entera se hace antes; (double)1/2 vale 0.5. No se puede castear el lado izquierdo de una asignación.

Operadores: aritméticos (+ − * / % con / entera entre enteros), relacionales (== != < > <= >=), lógicos (&& || !), asignación compuesta (+= −= *=), incremento (++i antes, i++ después), condicional (?:), sizeof. Precedencia: () → ++ −− ! (cast) → * / % → + − → relacionales → == != → && → || → asignación. Las expresiones lógicas valen 0 (falso) o distinto de 0 (verdadero).

E/S: con <stdio.h>: printf("formato", args) con %d (int), %hd (short), %ld (long), %f (float/double), %lf (double; en printf %f vale), %.2lf (dos decimales), %c, %s, %x, %%, \n, \t. scanf(" %d", &x) necesita la dirección (&) salvo para cadenas (ya son punteros) y %lf para double; el espacio antes de %c o %d descarta blancos y saltos pendientes. Constantes con #define PI 3.14159 o const. Bibliotecas: <math.h> (sqrt, pow, fabs; compilar con -lm), <stdlib.h> (rand, srand, malloc), <string.h> (strlen, strcpy, strcmp), <ctype.h> (isalpha, isdigit, isprint), <time.h> (time).

Explicación ampliada

Tipos de datos y por qué importan

Cada variable en C tiene un tipo que decide cuántos bytes ocupa y cómo se interpretan sus bits: char (1 byte), int (normalmente 4), float (4) y double (8). Con enteros, la división trunca: 7/2 vale 3. Si algún operando es real, la operación se hace en real: 7/2.0 vale 3,5.

Operador %: resto de la división entera, solo para enteros; el signo del resultado sigue al dividendo. Las conversiones explícitas (casting) se escriben (double)x y se aplican antes de la operación: (double)(a/b) sigue dividiendo como enteros.

Entrada y salida con formato

printf usa especificadores: %d entero, %f real, %c carácter, %s cadena. Con modificadores: %5.2f = ancho 5 y 2 decimales; %-5d = alineado a la izquierda; %05d = relleno con ceros.

scanf necesita la dirección de la variable (&x) y el especificador exacto: %d para int, %lf para double. El error más común de examen: olvidar el & o usar %f con un double. El espacio inicial en " %c" evita leer el salto de línea pendiente.

Desarrollo teórico a fondo

1Tipos de datos en C

  • Enteros: char (1 byte), short, int (normalmente 4 bytes), long. Con o sin signo.
  • Reales: float (4 bytes), double (8 bytes).
  • Carácter: char, que guarda un código (ASCII): 'A' vale 65.
Cuidado. División entera: 7/2 vale 3, no 3,5. Si uno de los dos es real (7/2.0), la división es real. El operador % da el resto.

2Variables, constantes y expresiones

  • Una variable es un nombre para una posición de memoria con un tipo. Hay que declararla e inicializarla antes de usarla: sin inicializar, contiene basura.
  • Asignación = frente a comparación ==: confundirlos es un error clásico.
  • Precedencia: *, /, % antes que +, -. Si dudas, pon paréntesis.
∴Entrada y salida con printf y scanf
  • Los formatos: %d (int), %f (float), %lf (double en scanf), %c (char), %s (cadena).
  • scanf("%d", &n);: el & pasa la dirección de la variable para que scanf pueda escribir en ella.
Cuidado. Olvidar el &, o usar un formato que no corresponde al tipo, da resultados absurdos o hace fallar el programa.

Lo que tienes que saber

  • División: 7/2 = 3, 7%2 = 1, 7/2.0 = 3.5, (double)7/2 = 3.5, (double)(7/2) = 3.0.
  • int a=5; b=a++ + ++a; es indefinido: no lo escribas; x=*++p+i con p→a[0]: avanza p a a[1] y suma i.
  • Formatos: %d int, %ld long, %hd short, %f/%lf double, %c char, %s cadena, %5.2f ancho 5 con 2 decimales.
  • scanf(" %c",&ch) — el espacio evita leer el Enter anterior. scanf("%s",cad) sin &.
  • Números aleatorios: srand(time(NULL)); r = rand()%N; (0…N−1).

Cómo se resuelve

  1. Para «¿qué imprime?»: anota el tipo de cada subexpresión; si los dos operandos son enteros la división es entera.
  2. Resuelve de dentro a fuera respetando precedencia y asociatividad (asignación de derecha a izquierda).
  3. Comprueba los formatos de printf frente a los tipos: un %d con un double imprime basura.

Trampas típicas

  • Olvidar & en scanf (o ponerlo en una cadena).
  • Comparar con = en vez de ==.
  • Creer que (double)(1/2) es 0.5.
  • %lf con float en scanf (float usa %f).

Problema tipo

Enunciado

(Test febrero 2019) ¿Qué imprime?

#include <stdio.h>
int main(void) {
    int a[5] = {10,20,30,40,50};
    int *p = a, i = 2;
    printf("%d", *++p + i);
    return 0;
}

Y: double x = (double)(1/2); printf("%.1lf", x);

✓Ver solución paso a paso

++p hace que p apunte a a[1] (20); *++p + i = 20 + 2 = 22 (opción d). La segunda imprime 0.0: 1/2 es división entera.

Ejercicios resueltos

Intenta cada uno antes de desplegar la solución.

Ejercicio 1 · División, módulo y casting

¿Qué valores producen 7/2, 7/2.0, (double)7/2, 7%2, -7/2 y -7%2?

✓Ver solución paso a paso

Ejecutando printf("%d %.1f %.1f %d %d %d", …):

3 3.5 3.5 1 -3 -1

Observa que -7/2 da −3 (trunca hacia cero, no hacia −∞) y que -7%2 da −1: el resto toma el signo del dividendo.

Ejercicio 2 · Formatos de printf

¿Qué imprime printf("[%5.2f|%-5d|%05d|%c]", 3.14159, 42, 42, 'A')?

✓Ver solución paso a paso
[ 3.14|42   |00042|A]

%5.2f ocupa 5 caracteres con 2 decimales (hay un espacio delante); %-5d rellena con espacios a la derecha; %05d rellena con ceros.

Ejercicio 3 · Desbordamiento y conversión implícita

(a) Un unsigned char c = 250; se incrementa con c += 10;. ¿Qué vale? (b) int x = 5; double y = x/2;. ¿Qué vale y?

✓Ver solución paso a paso
4
2.0

(a) \(250+10=260\) no cabe en 8 bits (máximo 255): se guardan los 8 bits bajos, \(260-256=4\).

(b) La división x/2 se hace entre enteros (da 2) y solo después se convierte a real: y vale 2,0, no 2,5. Para obtener 2,5 hay que escribir x/2.0 o (double)x/2.
