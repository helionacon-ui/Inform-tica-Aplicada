# Informática Aplicada · Guía para aprobar (UPCT, GIEyA)

Guía de estudio no oficial de Informática Aplicada (1.º GIEyA, UPCT), construida con las diapositivas UD0-UD4 del curso 2021/22, la lista cerrada de preguntas de teoría con las respuestas del profesor, el boletín de prácticas de C y SQLite y la recopilación oficial de problemas de exámenes 2013-2019: 9 temas con figuras interactivas (ciclo de la CPU, conversor binario/C2/IEEE 754, trazas de algoritmos y bucles, «¿qué imprime?», burbuja y búsqueda binaria, pila de la recursión, jerarquía de memoria, SQL con resultado real), 40 preguntas de la lista cerrada respondidas, test interactivo de examen con la regla real (−1/3 por fallo), 10 problemas de examen resueltos en C (compilados y probados) y chuleta de C y SQL.

Web: https://helionacon-ui.github.io/Inform-tica-Aplicada/ · Índice de guías: https://helionacon-ui.github.io/GIEIA-UPCT/

Sitio estático (HTML + CSS + JS). Sin dependencias ni build.
