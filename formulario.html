Chuleta de C y SQL

Representación

  • C2: invertir bits y sumar 1; rango [−2ⁿ⁻¹, 2ⁿ⁻¹−1]
  • Hex ↔ binario: grupos de 4 bits; octal: de 3
  • IEEE 754: signo + (exp+127) + mantisa sin el 1
  • n bits para m símbolos: 2ⁿ ≥ m

Esqueleto de un programa

  • #include <stdio.h> (+ math, string, ctype, stdlib, time)
  • prototipos → main → funciones
  • int main(void){ … return 0; }
  • #define MAX 100

E/S

  • printf("%d %ld %f %.2lf %c %s")
  • scanf(" %d",&x) · " %lf",&d · " %c",&ch · "%s",cad
  • El espacio inicial come blancos y Enter
  • & siempre salvo cadenas y punteros

Control

  • do{pedir}while(fuera de rango); — validación
  • do{menú;switch(op){case…break;}}while(op!=salir);
  • for(i=0;i<n && !enc;i++) — búsqueda con bandera
  • Centinela: while(x!=0)

Vectores y matrices

  • int v[N]; for(i=0;i<N;i++)…
  • Burbuja: pasadas de vecinos con temporal
  • Binaria: centro y descartar mitades (ordenado)
  • void f(int v[],int n) · int m[][COLS]

Funciones y punteros

  • Prototipo: tipo f(tipos);
  • Por referencia: void f(int *x) + llamada f(&a) + dentro *x
  • Vectores ya van por referencia
  • int *p=&x; *p=5; · p=(int*)malloc(n*sizeof(int)); free(p);
  • Recursión: caso base + problema menor

Cadenas

  • char s[N]; scanf("%s",s); termina en \0
  • strlen, strcpy, strcmp, strcat
  • isalpha, isdigit, isprint, toupper
  • Recorrer: while(s[i]) i++;

SQL

  • SELECT campos FROM t1,t2 WHERE t1.fk=t2.pk AND cond;
  • «sin»: NOT IN (SELECT…) / NOT EXISTS
  • «el más»: = (SELECT MAX(…) FROM …)
  • «cuántos por cada»: GROUP BY … HAVING
  • COUNT, AVG, MIN, MAX, DISTINCT, ORDER BY
  • FK: ON DELETE/UPDATE CASCADE · NO ACTION · SET NULL

Aleatorios y tiempo

  • srand(time(NULL)); una vez
  • rand()%N → 0…N−1
  • rand()%2 moneda al aire
