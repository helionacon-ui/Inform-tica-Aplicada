UD2 Programación en C · Tema 6

Tipos estructurados de datos: vectores, matrices y cadenas

UD2 Programación en CProblemas en C

Desde cero

Objetivo: Declarar y recorrer vectores y matrices, pasarlos a funciones, buscar (lineal y binaria), ordenar (burbuja) y manejar cadenas de caracteres.

Un vector almacena secuencialmente en memoria una cantidad fija de elementos del mismo tipo, accesibles por índice de 0 a tamaño−1: int v[10]; float a[100]; char s[3]={'d','5','*'}; short serie[]={1,3,6};. Son estructuras estáticas (no crecen); C no comprueba los límites. Recorrido con for; sizeof(v)/sizeof(v[0]) da el número de elementos (solo en el ámbito donde se declaró). Matrices: int m[TAM][TAM], recorrido con dos for; filas y columnas; en funciones hay que indicar las dimensiones salvo la primera: void f(int m[][TAM]).

Los vectores se pasan a funciones por referencia (se pasa la dirección del primer elemento: void f(int v[]) o int *v), así que la función puede modificar el original; por eso f1(a) con v[2]=4 cambia a[2]. Para reservar memoria en ejecución: int *v = (int*)malloc(n*sizeof(int)); … free(v);.

Búsqueda: lineal (media n/2 comparaciones, máximo n) y binaria en vector ordenado (mitad y descartar; máximo el menor n con \(2^n>\) tamaño). Ordenación: burbuja (tamaño−1 pasadas, en cada una compara a[i] con a[i+1] e intercambia con una variable temporal; coloca el mayor al final; \(O(n^2)\)); selección e inserción como alternativas.

Cadenas: vectores de char terminados en '\0': char pal[MAX]; scanf("%s", pal);; recorrido while (pal[i]) i++; o con strlen; strcpy, strcmp, strcat de <string.h>; isalpha, isdigit, isprint, toupper de <ctype.h>; vector de cadenas char *dic[]={"casa","pelota"} (ahorcado). Un número se descompone en dígitos con % 10 y / 10 (palíndromo).

Explicación ampliada

Vectores y matrices: la memoria como una fila de cajas

Un vector int v[6] reserva 6 enteros contiguos, numerados de 0 a 5. Acceder a v[6] es un error (C no lo comprueba: lee o escribe memoria ajena). Se recorre con un for; el patrón fundamental es el de máximo: inicializar con el primer elemento y comparar con el resto.

Cadenas de caracteres

En C una cadena es un vector de char que termina en el carácter nulo '\0'. Una cadena de 4 letras necesita un vector de al menos 5. strlen cuenta hasta el nulo (sin incluirlo); no se pueden asignar ni comparar cadenas con = o ==: hay que usar strcpy y strcmp (de <string.h>).

Al construir una cadena a mano, no olvides escribir el '\0' final; si falta, printf("%s") seguirá imprimiendo basura hasta encontrar un nulo.

Desarrollo teórico a fondo

1Vectores (arrays)

  • Un vector es una colección de elementos del mismo tipo en memoria contigua: int v[10];.
  • Los índices van de 0 a n−1.
  • C no comprueba los límites: v[10] en un vector de 10 escribe fuera y puede dañar otros datos o romper el programa.

Patrones: recorrer con for, sumar, buscar un máximo, buscar un valor, invertir, ordenar.

∴Ordenar y buscar: lo que hay que entender
  • Búsqueda secuencial: recorre uno a uno. Coste proporcional a \(n\).
  • Búsqueda binaria: solo sobre un vector ordenado. Mira el elemento central y descarta la mitad cada vez: coste proporcional a \(\log_2n\).
  • Ordenación (burbuja, selección, inserción): comparan e intercambian elementos; coste proporcional a \(n^2\). Para el intercambio hace falta una variable auxiliar.

2Matrices y cadenas

  • Matriz: vector de vectores, int a[3][4];. Se recorre con dos bucles anidados (filas y columnas). En memoria se guarda por filas.
  • Cadena: un vector de char que termina en '\0'. Una cadena de \(n\) letras ocupa \(n+1\) posiciones.
Cuidado. Las cadenas no se comparan ni se copian con == o =. Usa strcmp, strcpy y strlen (de string.h).

Lo que tienes que saber

  • Burbuja: for(p=0;p<n-1;p++) for(i=0;i<n-p-1;i++) if(a[i]>a[i+1]){t=a[i];a[i]=a[i+1];a[i+1]=t;}
  • Binaria: ini=0; fin=n-1; while(ini<=fin && !enc){ m=(ini+fin)/2; if(v[m]==x) enc=1; else if(v[m]<x) ini=m+1; else fin=m-1; }
  • Máximo de una fila y su columna: max=m[f][0]; *col=0; for(j=1;j<TAM;j++) if(m[f][j]>max){max=m[f][j];*col=j;}
  • Inicializar matriz: dos for anidados; pintar: for filas { for columnas printf("%d\t"); printf("\n"); }.
  • Palíndromo de una cadena: for(i=0;i<n/2;i++) if(s[i]!=s[n-1-i]) return 0; return 1;

Cómo se resuelve

  1. Dibuja el vector con sus índices antes de programar; marca qué índice recorre qué.
  2. Para «buscar» devuelve 1/0 o la posición (−1 si no está) y usa bandera para cortar.
  3. Para matrices decide si recorres por filas (i exterior) o por columnas (j exterior) según lo que acumules.

Trampas típicas

  • Índices fuera de rango (v[n]).
  • Olvidar el '\0' al construir cadenas a mano (añadeLetra del ahorcado: while(letras[i++]); deja i una posición más allá: error del enunciado).
  • Comparar cadenas con == o copiarlas con =.
  • Pasar una matriz sin la segunda dimensión en el prototipo.

Problema tipo

Enunciado

(Problema de examen: punto de silla) Un punto silla es el máximo de su fila y el mínimo de su columna. Implementa leeMatriz (valores en [MIN, MAX] con validación), maximoFila, minimoColumna (devuelven el valor y por referencia la posición), puntoSilla y main.

✓Ver solución paso a paso
#include <stdio.h>
#define TAM 5
#define MIN 0
#define MAX 9
void leeMatriz(int m[TAM][TAM]);
int maximoFila(int m[TAM][TAM], int fila, int *columna);
int minimoColumna(int m[TAM][TAM], int columna, int *fila);
int puntoSilla(int m[TAM][TAM], int *fila, int *columna);
int main(void) {
    int m[TAM][TAM], f, c;
    leeMatriz(m);
    if (puntoSilla(m, &f, &c)) printf("Punto silla en [%d,%d] = %d\n", f, c, m[f][c]);
    else printf("No hay punto silla\n");
    return 0;
}
void leeMatriz(int m[TAM][TAM]) {
    int i, j, t;
    for (i = 0; i < TAM; i++) for (j = 0; j < TAM; j++) {
        do { printf("Valor [%d,%d]: ", i, j); scanf(" %d", &t); } while (t < MIN || t > MAX);
        m[i][j] = t;
    }
}
int maximoFila(int m[TAM][TAM], int fila, int *columna) {
    int j, max = m[fila][0]; *columna = 0;
    for (j = 1; j < TAM; j++) if (m[fila][j] > max) { max = m[fila][j]; *columna = j; }
    return max;
}
int minimoColumna(int m[TAM][TAM], int columna, int *fila) {
    int i, min = m[0][columna]; *fila = 0;
    for (i = 1; i < TAM; i++) if (m[i][columna] < min) { min = m[i][columna]; *fila = i; }
    return min;
}
int puntoSilla(int m[TAM][TAM], int *fila, int *columna) {
    int i, hayPS = 0;
    for (i = 0; i < TAM && !hayPS; i++) {
        maximoFila(m, i, columna);          /* columna del maximo de la fila i */
        minimoColumna(m, *columna, fila);   /* fila del minimo de esa columna */
        hayPS = (*fila == i);
    }
    if (!hayPS) { *fila = -1; *columna = -1; }
    return hayPS;
}

Clave del apartado d: fila y columna llegan como punteros, así que a las funciones auxiliares se pasan directamente (columna) o desreferenciados (*columna) según lo que necesiten.

Ejercicios resueltos

Intenta cada uno antes de desplegar la solución.

Ejercicio 1 · Máximo y posición

Para int v[6] = {7,3,9,1,9,4}, ¿qué valor máximo y qué posición devuelve el algoritmo del máximo con if (v[i] > mx)?

✓Ver solución paso a paso
max=9 pos=2

El 9 aparece en las posiciones 2 y 4. Con > estricto, solo se actualiza con un valor mayor, así que se queda con la primera aparición (pos = 2). Con >= habría dado 4.

Ejercicio 2 · Diagonal y triángulo superior

Para la matriz \(\begin{pmatrix}1&2&3\\4&5&6\\7&8&9\end{pmatrix}\), calcula la suma de la diagonal y la del triángulo superior estricto.

✓Ver solución paso a paso
diag=15 sup=11

Diagonal: 1+5+9 = 15. Triángulo superior (\(j>i\)): 2+3+6 = 11. Los dos bucles anidados recorren las 9 celdas; la condición selecciona cuáles se suman.

Ejercicio 3 · Invertir una cadena

¿Qué hace este código con s = "Hola"?

n = strlen(s);
for (i = 0; i < n; i++)
  r[i] = s[n-1-i];
r[n] = '\0';
✓Ver solución paso a paso
aloH 4

Copia cada carácter en orden inverso (\(r[0]=s[3]\), \(r[1]=s[2]\)…). La línea r[n] = '\0' es imprescindible: sin ella, r no sería una cadena válida.
